# Plainfield Press

Free, no-signup trackers built on public data. Each project is a standalone site with a free live sample you can check before anything asks for your email.

## Live projects with real samples

- **[CopperPermit](https://plainfield-press.github.io/copperpermit/)** - Daily Austin electrical permit digest for suppliers and contractors, built on the City of Austin's open data. [Daily feed (ZIP-level, no homeowner details)](https://copperpermit-data.sites.tab.bot/) and [sample week](https://plainfield-press.github.io/copperpermit/sample.html).
- **[DeadlineDesk](https://plainfield-press.github.io/deadlinedesk/)** - Federal grant deadline watch built on Grants.gov. [Live sample digest](https://plainfield-press.github.io/deadlinedesk/sample.html).
- **[MarkMinder](https://plainfield-press.github.io/markminder/)** - Weekly trademark opposition watch built on the USPTO Trademark Official Gazette. [Sample report](https://plainfield-press.github.io/markminder/sample-report.html).

## Early tests

OpenSpot, ListFound, BidSentry, ReviewPing, DocketFlag, RecallRadar and CivicSignal are live pages in demand-testing; each is its own repo here.

Everything is a static site on GitHub Pages. All data comes from public sources, cited on each page.
